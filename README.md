# Swedish Ports & Baltic Trade Monitor

An end-to-end, reproducible maritime data project: open data → Python pipeline with validation → composite index with robustness testing → interactive dashboard.

**Author:** Preeti Rajpoot · MSc International Financial Analysis (JIBS) · Malmö, Sweden

## Questions answered

1. How much cargo moves through Swedish ports, and how has the cargo mix changed since 2005?
2. Which Swedish ports are most resilient to volume shocks? (composite **Port Resilience Index**)
3. How does Sweden compare with Nordic and Baltic peers on growth, volatility and shock recovery?
4. How have container traffic and liner shipping connectivity developed in the region?

## Key findings (data to 2025)

- Swedish main ports handled **156.1 million tonnes in 2025**, −2.5% on 2024 and −10.9% below the 2018 peak: volumes have plateaued.
- Liquid bulk is the largest segment (32% of tonnage); container tonnage is up ~50% since 2005.
- **Skellefteå and Oskarshamn** lead the Port Resilience Index (2015–2025). Rankings are robust: under 2,000 random weightings the mean Spearman rank correlation with the equal-weight ranking is **0.90**.
- In 2009 Swedish port volumes fell 14% vs 12% for the EU-27; in 2024 Sweden was 4% below 2019.
- Poland grew 4.4% a year since 2005 (+32% vs 2019); Latvia and Estonia handled over 40% less cargo in 2024 than in 2019.

## Data sources (public, no API key)

| Dataset | Content | Source |
|---|---|---|
| Eurostat `mar_go_am_se` | Goods handled in Swedish ports by port and cargo type, annual, thousand tonnes, 2005–2025 | [Eurostat](https://ec.europa.eu/eurostat/databrowser/view/mar_go_am_se/default/table) |
| Eurostat `mar_mg_aa_cwhd` | Goods handled in all ports, country level, 1997–2024 | [Eurostat](https://ec.europa.eu/eurostat/databrowser/view/mar_mg_aa_cwhd/default/table) |
| World Bank `IS.SHP.GOOD.TU` | Container port traffic (TEU) | [World Bank](https://data.worldbank.org/indicator/IS.SHP.GOOD.TU) |
| World Bank `IS.SHP.GCNW.XQ` | UNCTAD Liner Shipping Connectivity Index (to 2021) | [World Bank](https://data.worldbank.org/indicator/IS.SHP.GCNW.XQ) |

Note: the port-level dataset covers *main* ports, so Swedish totals differ slightly from the country-level "all ports" series used for the peer benchmark.

## Method

**Port Resilience Index (0–100).** For every Swedish port with a complete 2015–2025 series and ≥1 Mt in 2025 (13 ports), four components are min–max scaled across ports and equally weighted:

| Component | Metric | Direction |
|---|---|---|
| Growth | CAGR of tonnage 2015–2025 | higher = better |
| Stability | Std. dev. of annual log changes | lower = better |
| Downside protection | Maximum drawdown from previous peak | shallower = better |
| Cargo diversification | 1 − Herfindahl index of cargo-type shares (2025) | higher = better |

**Robustness.** Weights are drawn 2,000 times from a Dirichlet(1,1,1,1) distribution; for each port the 5th–95th percentile rank is reported, plus the average Spearman correlation with the equal-weight ranking. The approach mirrors the tail-risk and robustness testing used in my Master's thesis (VaR, Expected Shortfall, portfolio sorts).

**Validation.** The pipeline writes `data/processed/validation.md`, checking duplicates, negative values, that cargo types sum to the national total (±1%), series coverage, and which ports were excluded because of gaps or confidentiality (e.g. Malmö has no published figures after 2020).

## Run it

```bash
pip install -r requirements.txt
python src/fetch_data.py     # refresh raw data
python src/pipeline.py       # rebuild processed data + dashboard feed
open dashboard/index.html    # or: python -m http.server -d dashboard
```

## Limitations and next steps

- Annual data only; quarterly Eurostat series or AIS vessel-position data would allow near-real-time monitoring.
- The index uses volume-based measures; adding emissions (EU MRV), vessel calls or port-cost data would broaden "resilience".
- LSCI on the World Bank portal stops at 2021; UNCTADstat publishes newer quarterly values.
